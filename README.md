# CodeAlpha_Ecommerce 🛒

A full-stack e-commerce web application built as part of the CodeAlpha Full Stack Development Internship.

## 🚀 Live Features
- User registration and login with secure JWT authentication
- Browse products with details and pricing
- Add products to a shopping cart with quantity control
- Checkout flow that creates real orders in the database
- Order history for logged-in users

## 🛠 Tech Stack
**Frontend:** React (Vite), React Router, Axios, Context API
**Backend:** Node.js, Express.js
**Database:** MongoDB (Mongoose)
**Authentication:** JWT (JSON Web Tokens), bcrypt for password hashing
